# Issue governance delta

Canonical owner: [`falryn-docs/ISSUE-GOVERNANCE.md`](https://github.com/tyldra-org/falryn-docs/blob/main/ISSUE-GOVERNANCE.md). The repository-owned Roadmap and readiness auditors enforce its machine-checkable parts.

Before creating, editing, routing, or implementing an issue:

- resolve native parent, children, blockers, milestone, assignee, labels, Roadmap item, Status, Priority, and Readiness;
- use the exact affirmative standalone declaration only for genuinely parentless standalone work;
- preserve milestone and dependency coherence;
- keep parents out of actionable leaf delivery ordering;
- never infer readiness from prose, board position, activity, or blocker absence.

Run the auditor after governance mutations and require zero diagnostics before Next routing or delivery.
